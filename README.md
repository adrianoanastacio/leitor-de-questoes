# Leitor de Questões — versão para tablet

App web instalável do Leitor de Questões (leitor de PDF de livros didáticos centrado em questões: marcar feitas, revisar, matérias e modo prova).

- Abra o site no Chrome do tablet e toque em **Instalar app**.
- Os PDFs e as marcações ficam guardados só no aparelho (IndexedDB do Chrome). Nada é enviado para este repositório nem para a internet.
- Para levar os dados entre o PC e o tablet, use **Meus PDFs → Exportar dados / Importar dados**.

Este repositório contém só a versão já montada (gerada por `node build-web.js` no projeto do PC).
